# scop
A program to parse and render .obj files, built with C++17 and Vulkan.
The foundation for ft_vox and ft_minecraft, designed with scalability as the priority.

![Hero Image](https://github.com/xwojtuss/scop/blob/4a4ed077429917da564de1cc143e8ebeb72c425b/scop/hero.png)
![Animation Image](https://github.com/xwojtuss/scop/blob/4a4ed077429917da564de1cc143e8ebeb72c425b/scop/animation.gif)

## Prerequisites

- C++17 compatible compiler
- GNU Make
- Vulkan SDK
- GLFW

## Getting Started
After cloning the repository you can build the project using make:

```bash
make
```

Then run the executable:
```bash
./scop
```
